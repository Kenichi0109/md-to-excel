# Markdown → Excel 仕様

## 入出力

UTF-8のMarkdownファイル1件を、単一シートの `.xlsx` に変換するCLI。入力ファイルの内容を要約・改変しない。既存の出力ファイルは上書きしない。既存Excelテンプレートへの挿入や一括変換は対象外。

## 配置

| 要素 | 開始列 | 処理 |
|---|---|---|
| H1～H6 | A | 見出しごとに独立行。レベルが深いほどセル内字下げ。 |
| 段落・目次・リスト | B | 文書順。長文は文字幅を考慮して句読点・空白付近で分割。段落間に空行。 |
| コード | B | 元の1行をExcelの1行に置き、インデントと空行を保持。 |
| 表 | B以降 | 表の左上をB列とし、列を右へ展開。 |
| 画像 | B | 実画像をブック内に埋め込み。 |

見出しが増えても本文の開始列は変えない。文字は標準サイズの黒、塗り・飾り罫線・結合セル・固定表示なし。列幅はExcel標準を使い、長い文字列は右側の空セルへ表示する。

## リンク

Markdownの通常リンクとURLをクリック可能にする。段落中に複数リンクがある場合、本文の後に個別のリンク行を追加する。Markdown由来の文字列はExcelの数式として実行されないよう文字列型で保存する。

## 画像

HTTP(S)またはMarkdownと同じフォルダ以下の相対パスを読み込む。PNG、JPEG、GIF、BMPに対応し、1画像15MBまで。縦横比を維持し、大きい画像だけ最大幅940pxに縮小する。行高を15.75ptと明示し、表示誤差を見込んで画像の高さを行数に換算する。画像の前に1行、後に少なくとも2行の余白を設ける。

取得失敗時は位置に代替文を入れて警告を出す。他の本文の変換は続け、終了コード2で画像欠落を伝える。通常成功は0、変換失敗は1。

## 確認項目

- 浅い・深い見出しが混在しても、見出しはA列、本文はB列。
- 日本語の長文とコードの内容が欠落しない。コードの改行・インデントが残る。
- 画像がブック内に存在し、確保した行の高さが画像の高さを超え、次の文章と重ならない。
- 通常リンクとURLがクリック可能。画像取得失敗時は代替文と警告が残る。
